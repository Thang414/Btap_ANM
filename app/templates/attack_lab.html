📐 Sơ Đồ Cơ Chế Mã Hóa Lai (Hybrid Encryption Architecture)

  [ Tệp gốc Plaintext ] ──> [ Mã hóa AES-256-GCM ] ───────────> [ Ciphertext + Auth Tag ] ──┐
                                      ▲                                                      │
                                      │ (Khóa ngẫu nhiên)                                    │
                              [ Khóa phiên AES-256 ]                                        ├──> [ Tệp .locked ]
                                      │                                                      │
                                      ▼                                                      │
  [ RSA Public Key (C2) ] ──> [ Mã hóa RSA-OAEP ] ───────────> [ Khóa AES bị bọc (256B) ] ──┘
                                                                           │

                                                             RSA Private Key của C2!)
